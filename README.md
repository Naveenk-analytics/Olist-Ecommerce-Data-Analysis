# Olist E-commerce Data Analysis

## Project Overview

This project analyzes Brazilian e-commerce data from Olist to explore order trends, delivery performance, customer activity, and order status.

The goal is to transform raw data into meaningful business insights that can support data-driven decision-making.

## Tools & Technologies

* Python
* Pandas
* SQL
* Excel
* Power BI
* Git & GitHub

## Project Objectives

* Analyze order volume and order status.
* Examine delivery performance and delays.
* Identify monthly order trends.
* Investigate missing and invalid data.
* Prepare analysis results for business reporting.

## Project Workflow

1. Data inspection and quality checks using Python.
2. Data preparation and analysis.
3. SQL database setup and querying.
4. Exporting analysis results and visualizations.
5. Building an interactive Power BI dashboard.

## Key Findings

* The dataset contains 99,441 orders.
* The dataset contains multiple order statuses, including delivered, shipped, canceled, and unavailable.
* Among eligible delivered orders, the average delivery time was approximately 12.56 days.
* Delivery dates and missing values were examined as part of data-quality analysis.

## Project Files

* `inspect_data.py` — initial data inspection.
* `setup_sql.py` — SQL database setup.
* `sql_analysis.py` — SQL analysis workflow.
* `outputs/` — selected analysis results, charts, and reports.

## Skills Demonstrated

Python data analysis, SQL querying, data quality checks, exploratory data analysis, visualization, and project documentation.
